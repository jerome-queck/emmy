# Capture boundary review mapping

This mapping is proposed for independent source review. It does not advance `coverage.json`, its reviewed commit or any digest pin. The existing four TLC graphs and25 paired model/source witnesses remain required. Their assumption of already captured records does not prove provider pagination, JSON parsing, complete raw-byte acquisition, arbitrary history completeness or cloud transport.

| Production owner | Behavior | Behavioral witness |
| --- | --- | --- |
| `scopeConfig` | Separate caller-approved root, namespace/folder, automation and optional control authority; exact immutable inventory ID/raw pin | Scope rejection, immutable fixture, unapproved-automation source mutant |
| `pageListing` | Before/after generation, exact cursor chain, explicit EOF, totals, total page bound | Interrupted generation, skipped cursor, missing page tests and source mutants |
| `inventoryOf` | Distinct explicit snapshot pages or scope-pinned canonical complete-history inventory | Both modes; wrong ID/hash and non-history shape rejection |
| `capturedRecords` | Root200 and file5000 total; exact unique locations, all listed objects, size/hash, canonical UTF8/strict JSON, schema and content digest | Wrong parent/size/hash/name, missing objects, invalid UTF8, duplicate keys, global bound copied-source witnesses |
| `projectReadView` in `automation-reporting.mjs` | Canonical whole-history aggregate before existing scope/summary/detail/list/get | Filesystem equivalence across actions, filters, finding pages and historical revisions |
| Existing `aggregate` | Complete/valid/conflict guards; original clocks, ancestry, attempts, null/unbound reports, scoped receipts, reported assurance | Existing mapped suites plus missing predecessor, conflict and future-envelope copied-source controls |
| `consumeCapture` | Exact raw input hashes, evaluation clock, rules, request and output digest; no writes/provider latest claim | Raw whitespace hash and clock/query changes; source code review |
| Generated `cloudMain` consume | Supported bounded read-only CLI; raw bytes passed to boundary; no repository needed | Copied standalone fresh process outside repository, duplicate options and integer rejection |

`capture-drive.mjs` copies the actual production dependency closure into fresh temporary directories. Fifteen named baseline/mutant/restored pairs require the designated concrete wrong returned projection. Import occurs outside the refusal catch. A missing anchor, import error or mutant exception fails. Baselines may explicitly refuse corrupt structure or return incomplete diagnostic bodies, according to the contract. These source controls are behavioral witnesses, not new TLC properties.

Review the actual extraction diff: publication code and awaits are unchanged; aggregation code is unchanged. `projectReadView` receives the same snapshot and request as the former filesystem tail; it avoids mutating snapshot records and retains full aggregation before filtering. Review every new guard and source witness, output pagination, byte/size cap, schema discrepancy and provenance field. Structural schemas cannot express all cross-field constraints, exact raw-byte equality, pins or global totals; runtime checks remain authoritative.

Assumptions: supplied scope is approved separately; hashes are collision-free; pinned inventory approval concerns a complete history; snapshot pagination evidence comes from a mechanism supporting that contract. The implementation verifies internal consistency and exact supplied bytes. It does not authenticate provider truth, unseen history, atomic/global latest state, collector operation, authority strings, workload execution, scheduling, delivery or adoption. Actual cloud connector capability is a separate parent-owned gate. Stale binding/collector metadata supplies no read gate.
