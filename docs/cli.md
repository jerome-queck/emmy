# Agent CLI reference

Generated by `npm run agent -- maintain --write` from `src/metadata.mjs`. Every command prints one JSON object. Use `node scripts/agent.mjs` when piping JSON. npm also prints its script banner.

Global options are `--root <repository>` and `--json`. Default root is this checkout. JSON is always the output format. Private state lives in the selected root's ignored `.local/` directory.

| Command | Options | Purpose | Feature |
| --- | --- | --- | --- |
| help | none | List commands and JSON contracts. | orientation |
| doctor | none | Check runtime, public registry, bindings, and generated references. | orientation |
| catalog | none | Read public projects, source claims, capabilities, tools, and probes. | orientation |
| snapshot | `--import <value>` required | Import a scoped, timestamped inventory into private storage. | orientation |
| brief | `--snapshot <value>` required, `--as-of <value>` required | Read one retained snapshot with its age and coverage gaps. | orientation |
| plan | `--request <value>` required, `--snapshot <value>`, `--as-of <value>` required | Publish an immutable task proposal. Native products dispatch it. | routing |
| receipt | `--task <value>` required, `--import <value>` required | Import an attributed result for one task. | evidence |
| assess | `--task <value>` required, `--receipt <value>` required, `--revision <value>` required, `--as-of <value>` required | Assess exact identity, contradictions, and local artifact bytes. | evidence |
| probe | `--id <value>`, `--nonce <value>` required | Publish a proposed Dot onboarding packet with eight probes. | routing |
| maintain | `--check`, `--write` | Compare or regenerate public references without changing review records. | upkeep |

Exit 0 means the command completed and its applicable checks passed. Exit 2 means invalid input, corrupt storage, or an operational error. Exit 3 means a valid proposal needs observation, an assessment lacks or contradicts evidence, or generated references drifted. These exit codes do not report native task execution.

`maintain` requires exactly one of `--check` and `--write`. `probe` selects all eight probes unless `--id` names one. `assess` checks one receipt per run. Preserve competing receipts and inspect each.
