# Local check assurance

`npm run check` runs thirty ordered groups through one local admission owner. It retains original child output and an exact receipt under ignored `.local/verification/local-assurance/`. The plan retains the twenty-eight producer and subsystem groups and adds reporting tests and formal checks.

Use Node 24 or later, locked verification dependencies and existing Java 21. If the default TLC cache is missing, the gate runs the existing publication verifier's hash-pinned acquisition before binding the checked run. It installs no new toolchain. Corrupt existing jars and missing explicit jar overrides refuse. Existing `EMMY_JAVA_BIN` and `EMMY_TLC_JAR` selections remain subject to version/hash checks. Tool preparation alone reports `tools-ready` with no source-review/model pass.

```sh
npm run check
npm run check -- --base <local-ref-or-commit>
```

The default base is `HEAD`. A supplied base reference is resolved locally before every suite. No fetch occurs. The result prints `receiptFile` and `receiptDigest`. Exit zero requires every fixed suite to finish successfully against unchanged observations. Failure or drift exits one and retains original suite diagnostics inside the existing CI upload root. An interrupted owner may leave output without a terminal receipt; that output cannot qualify. A rerun gets a new directory and preserves earlier failures.

To assess one exact receipt, write a private request with `receiptFile` and the exact `receiptDigest` printed by the run, then invoke:

```sh
node scripts/agent.mjs assurance --file <private-request.json>
```

This rereads the receipt and original output, replays production transitions and reacquires local observations. It runs no suite. `current-local-reported` exits zero. Failed, incomplete, reordered or changed runs exit three. Invalid input, a wrong receipt digest or unreadable evidence exits two. Missing evidence never passes.

## Observed binding

The binding includes canonical checkout path, HEAD, base reference/resolved commit, merge base, complete working-source tree, fixed suite digest, tracked and nonignored untracked bytes, executable bits and tracked deletions. Ignored private evidence is outside source. Source symlinks refuse because their external closure is unknown. The tree uses an isolated temporary Git index; the real index is preserved. The Markdown suite receives that exact inventory through `--tree`, so new reviewed files participate without staging them. Standalone Markdown checking keeps its tracked-index default.

Installed dependency files are observed separately from source and lockfile. A dependency root symlink binds its resolved directory and contents; external links inside that directory refuse. Selected Node and Java executable bytes/versions, pinned TLC jar, platform, architecture, hostname and named runtime environment settings are also bound. These are comparable local observations, not authenticated native host identities or a complete operating-system dependency closure.

The runner observes before and after each child and at completion. Drift refuses subsequent admission. Assessment observes before and after reading retained outputs. These are separate filesystem reads, not an atomic snapshot. A file changed and restored between observations can escape detection.

## Verification ownership

`src/assurance.mjs` owns the fixed plan and synchronous `assuranceTransition`. `src/local-assurance.mjs` owns acquisition, processes, output and receipt parsing. `scripts/check.mjs` and the metadata-defined `assurance` command call those owners. There is no alternate production command-list option, resume operation, mutable latest-success file or new journal record.

The shared empirical driver includes `local-assurance`. Its isolated fixture substitutes a labelled two-command plan in copied source and drives actual package/agent entry points. It checks source/base/head/dependency movement, failed and interrupted processes, incomplete/reordered results, environment mismatch and corrupted output. Cold-cache controls feed existing pinned jar bytes through an intercepted synthetic fetch, without network acquisition; missing overrides and corrupt caches refuse. Full `npm run check` separately executes the complete production plan.

The [local assurance formal skill](../.agents/skills/local-assurance/SKILL.md) checks a finite graph generated by calling the actual reducer. TLC asserts complete coverage, clean acceptance and terminal refusal. Paired mutations change copied production guards. Read every TLC result with `/statechart` by name. Filesystem acquisition and processes require empirical verification.

Hashes bind supplied bytes. Fabricated, consistently rehashed evidence cannot authenticate authorship or actual execution. Independent review remains external. This ingress changes no hosted check, GitHub protection, merge decision, installed runner, schedule or provider state. Every checkout and machine needs its own observations and checks.
